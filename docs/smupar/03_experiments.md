# 03 · 实验逐图笔记

## Fig.1（动机图）

左右两栏，横轴都是 peak learning rate（对数），纵轴 train loss，不同颜色 = 不同稀疏度 `s`。

- **左（Standard practice）**：最优 LR 随 s 漂移。注意 `s=0` 的最优在 2⁻⁹ 附近，而 `s=0.984` 的最优跑到 2⁻⁷ 以上——**差 4 倍**。所以"复用 dense 超参"天然是欠调。
- **右（SµPar）**：所有 s 的最优点几乎都落在 `2⁻⁶` 附近，曲线族几乎重合。

> 这条图是全文的"一句话证据"。如果只记一张图，记这张。

## Fig.3（LLM 主结果）

610M 模型，Chinchilla 20 token/param，SlimPajama。横轴 density（`2⁻⁶` 到 `2⁰`），纵轴 validation loss，三条线 SP / μP / SµPar。

读数：
- dense（density=1）时三者几乎重合 → **SµPar 不伤害 dense 性能**（重要，因为它是退化情形）。
- 随稀疏度增加，SP 与 μP 掉得越来越快，SµPar 形成 Pareto 前沿。
- 在 `density = 2⁻⁷`（99.2% 稀疏）：较 SP 好 **11.9%**，较 μP 好 **1.9%**（相对值）。

⚠️ 但作者在 Finding 4（Sec. 4.3 末）自己说明：这个差距**主要来自 SP/μP 的 LR 欠调**（因为训练 token 多，更新丢失梯度信息）。Fig.8 显示如果给 SP/μP 逐稀疏度重新调 LR，能追回一部分。所以"11.9%"不能解释成"方法本身更优"，而是"**同一套超参下更优**"。这个区别在引用时必须写清楚。

## Fig.5（激活尺度，机制核心）

横轴 density（对数，`2⁻⁴`…`2⁰`），纵轴 mean absolute activation（对数），两栏分别是 attention 与 feed-forward，按训练步 t=0..9 上色，3 个 panel 分别是 SP / μP / SµPar。

- SP / μP：density 从 1 降到 2⁻⁴，激活掉约 2 个数量级 → **消失**。
- SµPar：曲线基本水平。

我们的复现（`scripts/run_supar_probe.py`，见 `docs/smupar/02_derivation.md` §2.7）：SP 掉到 `0.062/0.255 ≈ 0.24`（= `√(1/16)` ✓），SµPar 保持 `0.98×`。**机制被证实。**

## Fig.6 / Fig.7（超参迁移：LR 与 init）

各 3 panel（SP / μP / SµPar），每条曲线一个稀疏度，竖线标出最优。

- Fig.6：SP 的最优 LR 漂移且不单调；μP 漂移更剧烈（注意 μP 的横轴范围被单独放大，说明最优值整体更小）；SµPar 全部落在 `2⁻⁶`。
- Fig.7：SP/μP 的最优 init std 出现**不连续**跳变。作者解释：嵌入层与 decoder 层的激活尺度不同，高稀疏度时嵌入的尺度占主导。SµPar 稳定。

⚠️ Fig.7 的实验只跑到"训练早期"（脚注 4：初始化差异大的模型后期会不稳定），所以这只是初始化阶段的性质，不是最终 loss。

## Fig.8（汇总：最优 LR 下的 loss vs density）

即使**给 SP/μP 每个稀疏度都选最优 LR**，SµPar 仍（大体）构成 Pareto 前沿：平均好 0.8%（对 SP）、2.1%（对 μP）。

→ 这张图很重要：它说明 SµPar 的收益**不全是调参**（否则给最优 LR 后三条线应该重合）。但注意"大体"——图上有交叉。

## Fig.9 / Fig.10 / Fig.11（Iso-Parameter 与 Iso-WPN，全篇最漂亮的部分）

**Iso-Parameter scaling**：改变宽度的同时改变稀疏度，使**非零参数总量**大致不变（`d=768,s=0` → `d=1088,s=0.5` → `1088→1536@0.75` → `2176@0.875`）。

- Fig.9：SP 的最优 LR 仍随稀疏度漂移；μP 也漂移；SµPar 稳定。
- Fig.10：最终 loss —— SP / μP 随稀疏度上升而"失谐"，SµPar 持续改善。
  ⚠️ 脚注 7 很重要：这**不是等 FLOPs 比较**（宽度增加会带来注意力与嵌入的额外 FLOPs，那些层没被稀疏化），87.5% 稀疏的模型训练 FLOPs 是 dense 基线的两倍而 loss 几乎不变。

**Iso-WPN**（Sec. 4.2）：固定每神经元非零权重数 `WPN = d_model · ρ = O(1)`。

- 此时 `m_d · m_ρ = 常数` → **μP 与 SµPar 的修正因子完全相同**，SP 也能用。
- Fig.11 实测：SP 的最优 LR 稳定在 `2⁻⁷`…`2⁻⁶`，曲线族基本对齐。

> 这个结论有普适价值：**如果你看到的稀疏 scaling 技巧"有效"，先检查它是不是隐式地固定了 WPN。** 这是全文我最欣赏的一段——它统一解释了一批既有工作，并给出可检验的判据（`η* ∝ 1/WPN`）。

## Fig.12（动态稀疏：失败案例）

RigL 与 GMP × SP/μP/SµPar 共 6 个 panel，都没有稳定的最优 LR：

- SP / μP：稀疏度越高，最优 LR 越高（因为信号变弱，需要更大步）。
- SµPar：**反向**（稀疏度越高最优 LR 越低）→ **过校正**。

机理（Sec. 4.4）：动态方法的掩码按幅度选，会使非零权重分布偏离高斯；而推导里的 `E[X ΔW] = d_in ρ · E[XW]` 依赖"权重独立同分布高斯"。掩码一旦相关性化，`ρ` 的补偿就过头了。

→ 这条负面结果其实很有价值：它说明 SµPar 的适用边界是**随机静态稀疏**，不是"所有稀疏"。
