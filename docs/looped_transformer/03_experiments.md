# 03 · 实验逐图笔记

> 写法说明：每条先写"图里到底是什么"，再写"我从中读出什么"，最后写"缺什么"。带 ⚠️ 的是我认为需要警惕的解读。

## Fig.2（核心图）

- **左**：训练时 $b=30$，推理时把循环跑到 100 次。误差单调下降到某个平台，**没有反弹**。
  → 固定点确实存在且稳定。⚠️ 但这是"训练目标要求 b 步内匹配"的直接结果，不算自发涌现。
- **右**：$k$（in-context 样本数）从 0→40 的误差曲线。looped（1/12 参数）几乎贴在 12 层标准模型上，都逼近最小二乘。
  → 主张成立：参数效率是真的。

## Fig.3（消融：输入注入）

- 有注入 vs 权重绑定。权重绑定在超过训练循环数后**迅速发散**（误差飙到 1 以上）。
  → 印证 2.2 的机理分析。这是全文最干净的一个消融。

## Fig.4（b × T 网格，linear）

三联图 `T=5/10/15`，每图 5 条线 $b \in \{12,20,30,40,50\}$，横轴是推理时的循环次数（0–200），虚线标出该模型的训练 $b$。

我的读数：

1. $b=12$（= 标准模型深度）在三个 T 下都不够——要么平台偏高，要么在 b 之后翘起来。
2. $T=5$ 平台明显偏高（约 3–5×10⁻²），$T=15$ 能压到 10⁻³ 附近。
3. $b$ 越大幅度提升越小；$T=15$ 时 $b=40$ 与 $b=50$ 几乎重合 → 存在饱和点。
4. **所有曲线都在达到自己的 $b$ 之前就平了**，符合"要求在 b 步内匹配"的目标函数设计。

## Fig.5 / Fig.14（样本效率）

- 固定训练集（不再每步新采样），横轴是**见过的不同 prompt/函数数量**（1k→80k）。
- looped 在 $d=5,10,20$ 三个维度上都用更少的独立 prompt 达到同样误差。
  → 参数少 → 容量小 → 更早进入"只能用正确算法"的区域。这个解释合理，但**同时意味着它是一种隐式正则**，与后面 OOD 变差的观察一致。

## Fig.6 / Fig.15 / Fig.16（OOD）

六个 OOD 场景：(a) 偏斜协方差 (b) d/2 子空间 (c) 噪声 (d) 查询与样本正交 (e) 查询等于某个样本 (f) 不同象限。

| 场景 | looped 相对 12 层 | 我的解读 |
|---|---|---|
| (a) 偏斜协方差 | **更好** | 简洁性偏置 ≈ 隐式正则，对病态输入更稳 |
| (b) d/2 子空间 | 相当或更好 | |
| (c) 加噪 | **双下降峰值更低** | 相当于加了轻微正则，噪声下更稳 |
| (d) 正交查询 | 相当 | |
| (e) 查询命中样本 | 相当 | |
| (f) 不同象限 | 能匹配到 20 层 | |
| **x 缩放 ×3**（Fig.6c） | **明显更差** | 没有学到"尺度不变"的算法，只在训练分布内像算法 |

⚠️ 关键：**能同时解释"更好"和"更差"的"简洁性偏置"假说没有被证伪**。作者也没做任何干预实验来定位机制（例如测输出对 ‖x‖ 的敏感度）。

## Fig.7（架构变化）

- 左：标准模型 L=1/2/4/8/12/20 的收敛曲线 vs looped L=1/2/4。
  → 层数越大收敛越快；**looped L=1 需要约 20 次迭代才能达到 8 层标准模型**。即"有效深度 > 层数"，但也说明循环步与层**不等价**（作者据此推断每层/每次循环学到的表示不同）。
- 右：固定 L=1,h=8，D 从 64→512，收敛随 D 提升，**D=256 饱和**；固定 D,h 改 L 差别不大，主要是速度；只改 h：2→8 变好，**8→32 变差**（因为 GPT-2 的每头维度 D/h 被压缩）。
  ⚠️ h 的结论其实是"每头维度"的结论，不是"头数越多越好/坏"。

## Fig.8（probing，最有信息量的一张）

做法：在第 t 层/第 t 次循环的输出 $Y_{t}$ 上，用一个带 softmax 序列注意力的 2 层 MLP 去回归两个目标探针：
- $X^{\top}y$（梯度方向）
- $w_{OLS}$（最优解）

结果：标准模型大约在第 10 层附近解码误差最低，之后**反而变差**（信息被后续层"混掉"）；looped 模型**每次循环都单调变好**。

我的解读：这是循环结构最强的间接证据——共享权重被反复使用于同一个精炼任务，而不是"一次算完再后处理"。⚠️ 但 probing 只能说明信息**线性/非线性可解码**，不能说明模型**实际使用**了它；而且探针只在 20 次迭代内、对照组是 $w=1$ 的固定任务（控制探针误差的下限）。

## Fig.9 / Fig.10 / Fig.11（更复杂的函数类）

| 任务 | 最优 (b,T) | 结果 |
|---|---|---|
| sparse linear (d=20, s=3, k=100) | (20, 10) | looped **优于** 12 层与 Lasso（<10 样本时尤其明显） |
| decision tree (depth 4, k=100) | (70, 15) | 匹配 12 层；与 3-NN、贪心树、XGBoost 同量级 |
| 2-layer ReLU NN (100 隐藏单元, k=100) | (12, 5) | 匹配 12 层与 2 层 NN+GD |

Fig.11 扫稀疏度 $s=1,3,6,9,12$（统一 b=30,T=15）：looped 在**所有稀疏度**上都不差于标准模型，样本少时更好。

⚠️ 决策树要 $b=70$ 才能稳定：这已经是 70 次单块前向 ≈ 70 层算力，而对比的 12 层模型只跑 12 层。**这个比较在算力维度上是吃亏的**。
